# 监控检索与 Playground 优化

本轮沿用 Direct API、现有鉴权、费用口径和存储保留策略，完善监控查询和请求调试流程。旧 LMArena 桥接功能继续按 README 的退役范围处理。

## 日志查询与交互

- 请求日志新增开始日期、结束日期、重置筛选、加载结果提示、手动重试和暂停自动刷新。搜索输入采用 300ms 防抖；相同的在途查询共用一次请求，筛选变化取消旧请求。旧响应、旧错误或其他标签页的结果不会覆盖当前提示。
- 日期按服务器本地自然日计算，结束日期包含当天；留空继续查询全部历史。`GET /api/monitor/logs/requests/query` 新增 `start_date`、`end_date` 和 `include_models`。日期格式为 `YYYY-MM-DD`，无效日期或倒置区间返回 400，页大小必须为 1–1000，偏移量不能为负。
- `include_models` 默认保持 `true`，兼容原有调用方。监控页面在首次查询及目录超过一分钟未更新时请求模型目录，其余刷新省略该查询；刷新模型目录保留当前选择。
- 最近日志只读取所需行，不再调用分页计数。分页查询在同一个 SQLite 读取事务内取得总数和列表；时间戳相同的记录按写入顺序稳定排序。
- SQLite 查询失败会交给现有文件回退处理，不再返回伪装成功的空列表。回退最多检索最近 1000 条，接口返回 `limited: true` 和提示，页面明确展示覆盖范围。
- `/monitor?search=请求ID` 可以直接定位对应记录，供 Playground 跳转使用。

## 轻量特征与代码结构

SQLite 新增 `has_reasoning`、`has_tool_calls` 两个可空字段，写入完成记录时从请求和响应中提取，最近列表、筛选列表和详情读取路径均返回。支持 Chat 工具调用和 Anthropic 内容块等已有记录形式，列表无需传输完整上下文。

旧记录新增字段保持 `NULL`，表示未记录，不批量扫描历史正文补算，也不改写历史费用。迁移和重复初始化已用隔离数据库验证，旧金额保持不变。

筛选条件收敛到 `utils/log_query.py`，特征提取位于 `utils/request_features.py`；SQLite 列表和详情共用行映射。日志交互移入 `js/monitor-logs.js`，原监控脚本保留实时连接和详情交互，减少页面主脚本承担的职责。

## Playground

每个模型、端点及协议在本页独立保留 JSON 草稿、流式开关、会话 ID 和工具选择。刷新能力目录或切换端点不会丢失编辑；关闭或刷新整个页面后清除草稿，不另行持久化请求内容。

插入工具只同步面板管理的原生工具，保留函数定义、未知工具和仍选中的原生工具参数。取消勾选某个已列出的原生工具后再写入，可移除该工具；需要的文件库、MCP 地址等参数仍由请求编辑者填写。新增 JSON 格式校验与排版、Ctrl / Cmd + Enter 发送以及对应监控日志链接。

响应传输结束后立即恢复发送按钮。阶段耗时单独读取，最多等待 5 秒，并使用请求版本识别过期结果；旧请求的结果不会覆盖新请求。中断后的已有输出继续保留，完整原始响应仍可下载。

Tokenizer 来源列表的未保存编辑不会被刷新覆盖，来源接口失败会单独提示，模型能力仍能加载。导航栏的过渡限定为颜色，避免窗口缩放时反复计算导航布局；窄屏文字保持单行，在导航栏内横向滚动。

## 验证与测量

- `python -X utf8 -m pytest tests -q --ignore=tests/legacy -p no:cacheprovider -o faulthandler_timeout=60 --maxfail=3`：387 项通过，耗时 38.32 秒。
- 最后的日志加载状态修正增加了一个回归案例，随后 `tests/test_monitor_workspace.py` 的 11 项测试全部通过。没有重复执行完整套件。
- 修改后的 `admin-gateway.js`、`monitor.js`、`monitor-logs.js` 通过 `node --check`；`git diff --check` 通过。
- 真实 SQLite 和 HTTP 路由覆盖日期、分页、通配符文字搜索、并发写入期间的查询快照、迁移、全部特征读取路径和文件回退。Chromium 测试覆盖取消与合并查询、过期结果、草稿切换、工具参数、信任列表编辑和异步耗时结果。
- 模拟接口截图检查覆盖监控和 Playground 的 1440px、390px 视口，文档宽度均与视口一致，表格在自身容器滚动。导航的小幅样式调整另经截图检查。

性能测量只读本机含 180,781 条记录的现有数据库，在相同事务快照内交替执行七组查询并取中位数。省略模型目录后的普通日志刷新数据库工作从约 8.00ms 降至 1.66ms；首次及目录更新时仍需读取目录。最近 50 条记录查询从约 0.23ms 到 0.20ms，原本已很快。这些是本机热缓存下的数据库查询时间，不包括网络、浏览器渲染或并发下的延迟。

本轮未重启正在运行的服务，也未调用真实计费上游。后端代码和新增字段在下次启动时加载、迁移；页面更新应与后端更新一起使用。真实配置、数据库、模型价格资料、截图和临时测量脚本均不进入 Git 提交。
