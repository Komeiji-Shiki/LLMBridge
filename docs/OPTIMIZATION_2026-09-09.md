# Codex 计价、统计性能与页面优化

## 计价口径

Codex 本地日志提供 Token 消耗，不提供订阅账单。本次按 2026-09-09 核对的官方标准 API 单价折算历史用量，金额明确标为估算。公开价格只作为当前价格快照，不推断历史折扣或实际扣费。

| 模型 | 普通输入 | 缓存输入 | 输出 |
| --- | ---: | ---: | ---: |
| GPT-6 Astra | 10 | 1 | 50 |
| GPT-5.6 Sol | 4 | 0.4 | 20 |
| GPT-5.6 Terra | 2 | 0.2 | 12 |
| GPT-5.6 Luna | 0.2 | 0.02 | 1.2 |
| GPT-5.5 | 5 | 0.5 | 30 |
| GPT-5.4 | 2.5 | 0.25 | 15 |
| GPT-5.4 mini | 0.75 | 0.075 | 4.5 |
| GPT-5.3-Codex / GPT-5.2-Codex | 1.75 | 0.175 | 14 |

单位为 USD / 百万 Token。依据为各模型的[官方模型页](https://developers.openai.com/api/docs/models)及[标准价格文档](https://developers.openai.com/api/docs/pricing)，程序和页面保留每个模型的直接来源链接。

普通输入扣除缓存命中和单独计价的缓存写入，推理量已经包含在输出中。Astra 和 GPT-5.6 系列的独立缓存写入价格为普通输入的 1.25 倍；其余模型未有独立写入价时，写入归入普通输入。长上下文遵循模型文档：Astra / GPT-5.6 按单次请求判断，GPT-5.5 / GPT-5.4 按完整会话判断，超过 272K 输入时输入与缓存乘 2、输出乘 1.5。日期过滤在会话档位确定后执行。

未公开价格的 auto-review、Spark 和未知别名保持未定价，不猜测模型映射。估算不包括快模式、工具、地区附加费，也不换算成额度百分比。Sol 当前报价包含官方活动价格，活动至少持续至 2026-11-21；核对日期仍需随价格更新维护。

按已经确认的规则，合计排除 `local-lmarenabridge` 的 Codex 用量，由网关记录提供这部分统计；Codex 单独视图仍完整展示。网关历史金额不改写，CSV 的来源、估算口径和日期筛选与页面一致。

## 性能与代码

- 网关 Token 统计从六次聚合查询收敛到三次，复用模型分组计算总量与币种汇总；保留全部异步接口。同一个只读事务快照上，重构前后的原有字段逐项一致。
- 相同的并发 Token 查询共享一次后台工作，单个客户端取消等待不会取消其他客户端的查询；模型配置变化会使旧缓存失效。
- Codex 按模型、日期、会话和上下文档位一次汇总，缓存未变化的查询结果；文件变化或强制重扫后失效。
- 首页统计不再等待运行概览接口返回；首屏并行加载，服务按默认 30 天预热。读取已有索引与后台扫描使用独立锁，首次导入显示进行中，完成后自动补齐；导出仍等待扫描完成。本机新进程通过真实统计路由读取已有索引，首个响应约 141ms，缓存响应约 5ms，不包括浏览器资源下载时间。
- 本机同一环境下，网关全量统计从约 406–464ms 降至约 225–304ms；Codex 已缓存重复汇总从约 79–84ms 降至约 0.2ms。首次扫描仍取决于日志量，以上不是网络或端到端延迟承诺。
- 每个监控连接只有一个发送任务，队列有界且保证顺序。慢连接超载后断开并重连、重新读取持久日志，避免广播任务无限堆积。
- JSONL 最近日志改为按块倒序读取，避免全文件 `readlines()`；分层错误列表排除成功请求。
- 关闭服务时停止已注册后台任务，再关闭共享连接和保存统计。

## 前端

概览将用量和金额前移，运行信息可展开查看；输入、缓存与输出金额分开展示。首页默认最近 30 天，提供 30d / 7d / 1d / 所有日期快捷按钮，按自然日统计并包含今天。每日 Token 与金额图上下排列、分别占满宽度。柱状图和占比图按需切换，刷新复用图表实例，保留图例选择。所有金额图表与卡片同步切换币种，过期请求的成功或失败结果不能覆盖新筛选。

长表格在自身区域滚动，表头固定，图表容器允许收缩。390px 截图检查中，管理概览的文档宽度从 1111px 修复为 390px。监控页压缩空状态与窄屏指标占用，日志区域提供独立滚动。暗色、平面、直角风格保持一致。

截图使用隔离模拟数据，性能测量只读本机统计数据；验证产物位于忽略的 `logs/optimization-qa/`，不提交会话、数据库或私人配置。协议转发、存储保留策略、鉴权与上游请求参数未作产品语义变更。
