# 审查后实施决定

用户已经批准以下范围，无需再次确认这些策略：

1. 所有模型统一保真，不再默认修改 strict、required 或递归 schema；迁移已有模型配置。
2. 所有维护中的协议入口使用同一重试边界：首个有业务意义的事件发给客户端前按规则重试，之后失败明确报告中断。
3. 保留现有 sticky/429/配额长期冷却规则，不改成短期冷却；修复执行不一致。
4. 客户端原样回传优先；网关持久化隔离的会话状态，对话连续 3 天未调用才清理缓存。
5. 轻量多人：稳定调用方 ID、按 Key 统计与隔离；无需注册系统。
6. 持久化失败处理由实现者决定，成功响应必须对应真实保存结果，安全撤销优先立即失效。
7. 图床 30 分钟；日志、完整对话、蒸馏数据永久保留直到用户主动清理，采用无损压缩。普通 tokenizer 正常运行，自定义远程代码按来源启用。上传上限由实现者给出可配置合理值。
8. 按调用时价格保存，历史金额不改写；当前价格重算为独立的只读分析功能。
9. 实现供应商原生工具和网关管理工具，不提供自建的 shell/任意文件/通用抓取执行器。
10. 提供能力诊断、请求 Playground、Gemini / OpenAI / 百炼 Qwen / DeepSeek 原生工具兼容、阶段耗时及监控页面优化。
